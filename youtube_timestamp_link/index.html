How the t= Parameter Works

YouTube reads a t= parameter at the end of a video URL: ?t=1m30s starts playback 90 seconds in, and &t=2h14m5s starts two hours in. The catch is the separator — ? if the URL has no parameters yet, & if it already has some (like tracking codes or playlist data). The generator inspects the URL and attaches the time parameter correctly every time, so you never think about question marks and ampersands.

Small Caveats Worth Knowing

Playback usually seeks to the nearest keyframe, so the first frame you see may appear a second or two before your exact timestamp on some videos; the playback position itself is still correct. And t= sets a start point only — YouTube shared links do not support an end time, so if you want someone to watch a segment, mention the end time in your message. If you need frame-exact precision for editing or citation, note the exact timecode shown in the player and quote it alongside the link.
