What This Favicon Checker Actually Tests

Paste any URL into the box above and hit Check Icon. Here's what happens behind the button.

First, the tool attempts a real, live load of https://yourdomain.com/favicon.ico. This is the file browsers request by default, and the check treats it the way a browser would: if the image loads, you get a green check; if the request fails — the file is missing, the path is wrong, or the server blocks it — you get a red X. No guessing, no assumptions carried over from some earlier crawl.

Second, it looks at the URL you typed and flags whether it uses HTTPS. Icons served over plain HTTP on an HTTPS page can trigger mixed-content warnings, so the protocol check is a quick hygiene pass worth having.

Third, it pulls your site's icon through Google's favicon service and renders it in two mockups: a browser tab and a mobile-style search result. That preview answers the question that matters most — not "does the file exist?" but "what do my visitors actually see?"

One honest limitation: the tool does not crawl your HTML looking for declared icons. It won't tell you whether your apple-touch-icon link tag is correct or whether an SVG favicon validates. The /favicon.ico check plus the visual previews cover the cases that affect nearly every visitor — but the touch-icon and manifest checks described below are on you.

Why a Broken or Missing Favicon Hurts Your Brand

Your favicon is the smallest piece of your brand and one of the most-seen. Every open tab, every bookmark, every history entry, and every mobile search result carries it. When someone has a dozen tabs open, they aren't reading titles — they're scanning tiny squares of color and shape. That's your icon doing recognition work at sixteen pixels.

When the icon is missing, browsers substitute a generic placeholder: a blank page or a gray globe. Next to a row of crisp brand marks, that placeholder reads as unfinished. It doesn't matter how good your product is — the first signal a new visitor gets is that this site couldn't be bothered with the details.

Google raised the stakes when it started showing site icons next to URLs in mobile search results. Your listing now competes visually before anyone reads a word, and a sharp, recognizable favicon can be the difference between a scroll-past and a tap. That's why icon health belongs in the same routine as title tags and meta descriptions. Run this check after any redesign, migration, or CMS switch — those are the moments icons quietly break.

Favicon Formats and Sizes: What You Actually Need

The favicon world has accumulated two decades of formats. Here is the short list that covers essentially everyone.

The .ico file is the old guard. It's a container that can hold multiple sizes — typically 16×16, 32×32, and 48×48 — in one file, and browsers have requested /favicon.ico from the site root since the beginning. Keep one there for legacy support and for any client that still asks by default.

The 32×32 PNG is the modern workhorse. PNGs are smaller than ICOs, support full transparency, and every current browser accepts them when declared with a link tag. If you ship only one declared icon, make it this one.

The 180×180 apple-touch-icon PNG serves iOS. When someone adds your site to their iPhone home screen, this is the image iOS uses — and iOS applies its own rounded corners and ignores transparency, so design it on a solid background.

SVG favicons are the optional upgrade. A single tiny vector file scales from a 16-pixel tab to a high-resolution bookmark bar with zero quality loss, and most modern browsers now support them. They're not universal yet, so treat SVG as a supplement rather than a replacement.

Put together — a multi-resolution .ico at the root, a 32-pixel PNG link tag, and a 180-pixel apple-touch-icon — and your icon renders correctly on virtually every browser and device shipping today.

How to Add a Favicon to Your Website

The minimum viable favicon takes about two minutes. First, create your icon and save it as favicon.ico, then upload it to your site's root directory — https://yoursite.com/favicon.ico. Browsers request this path automatically, so with most setups you don't even need HTML changes for the classic tab icon to appear.

Second, cover modern browsers and iOS with explicit link tags in your page's <head>: 

<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">

Third, verify. Run this checker to confirm /favicon.ico loads, then open your site in a fresh tab and look at the tab bar. If the old icon (or no icon) persists, you're almost certainly looking at a cached copy — hard-refresh with Ctrl+Shift+R on Windows or Cmd+Shift+R on Mac, or append a version query like favicon.ico?v=2 to force browsers to fetch the new file. Your Favicon Isn't Showing? Start Here

You uploaded the file, refreshed the page, and the tab still shows a blank page. Work through this list in order — the culprit is usually near the top.

  • Caching. Browsers cache favicons far more aggressively than regular images, sometimes for days or weeks. This is the cause in the large majority of "it's not showing" reports. Hard-refresh, test in a private or incognito window, or add ?v=2 to the icon URL to bust the cache.
  • Wrong path. The browser requests /favicon.ico from the root by default. If your file lives in /images/ or /assets/ without a matching link tag, the browser never finds it. Either move the file to the root or declare the real path with rel="icon".
  • Corrupt or unsupported file. A PNG renamed to .ico isn't a valid ICO file. If your icon opens in an image viewer but fails in the tab, re-export it with a proper favicon exporter instead of renaming the extension.
  • Missing touch-icon tags. Your tab icon can work perfectly while iOS home-screen bookmarks show nothing — that's a missing apple-touch-icon link tag, not a broken file.
  • Oversized files. A two-megabyte "favicon" will technically work but loads slowly and can time out on flaky connections. Keep icons small; a 32-pixel PNG should be single-digit kilobytes.
